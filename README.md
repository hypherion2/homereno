# 1615 MCH · Remodel studio

An interactive 3D model of the house with the original (aligned) plan and every remodel iteration stored as a numbered version.

- Open the site (or `index.html` in any modern browser; it loads the 3D library from a CDN, so it needs an internet connection).
- Pick a version on the left, switch levels, drag to orbit, and use the view buttons at the top right.
- Conceptual visualizations only, not engineering drawings. Any wall, stair or floor change needs structural and code review.

## Publish with GitHub Pages
1. Create a repository and upload `index.html` and this README to the `main` branch.
2. Settings -> Pages -> "Deploy from a branch" -> `main` / `(root)` -> Save.
3. After a minute it is live at `https://<username>.github.io/<repository>/`.

Note: a Pages site is reachable by anyone with the link, even if the repository is private.
